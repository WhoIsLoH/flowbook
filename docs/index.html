Three step types. One journey.

Describe the business path once — run it against API or UI.

http

API requests

POST /signup, capture tokens, chain Bearer auth. Simple JSONPath captures ($.field).

assert

Business checks

Expect status, JSON fields, or captured vars — assert the outcome that matters, not the DOM noise.

browser

Playwright UI

goto / fill / click / waitFor / capture when the API alone isn’t enough. Headless by default.

Install

      
Package name flowbook-cli on npm — binary is still flowbook.

      

        
# one-shot
npx flowbook-cli validate path/to/playbook.yaml
npx flowbook-cli run path/to/playbook.yaml

# or install
npm install -g flowbook-cli
flowbook run playbooks/auth-signup-checkout.yaml

# browser steps need Chromium once
npx playwright install chromium
